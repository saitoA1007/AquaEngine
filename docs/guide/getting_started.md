# はじめに

AquaEngine は DirectX 12 で作られたゲームエンジンです。
このページでは、エンジンを使ってゲームを作るときに最初に知っておきたい全体の仕組みを説明します。

## フォルダの構成

`Project/` の中は、おおまかに次のように分かれています。

| フォルダ | 役割 |
|---|---|
| `EngineSource/` | エンジン本体。描画・入力・当たり判定などの機能が入っています。ゲーム制作では基本的に**使うだけ**で、書き換えません。 |
| `Application/` | ゲーム側のコード。シーンやプレイヤー、敵などはここに書きます。 |
| `Resources/` | モデル・画像・音などの素材。起動時にエンジンが自動で読み込みます（[リソースの読み込み](resources.md)）。 |
| `Externals/` | 外部ライブラリ（assimp、ImGui など）。 |

## ゲームが動く流れ

`main.cpp` で `GameEngine::Engine` を作って `RunEngine()` を呼ぶと、エンジンが起動します。
そのあとは、エンジンが毎フレーム次のことを行います。

1. 入力を更新する
2. 登録されているゲームオブジェクトの `Update()` を呼ぶ
3. 今のシーンの `Update()` を呼ぶ
4. 当たり判定を行う
5. シーンとゲームオブジェクトの `Draw()` を呼び、画面に描画する

ゲーム側で書くのは、主に **シーン** と **ゲームオブジェクト** の2つです。

- **シーン**（`IScene`）：タイトル画面・ゲーム画面のような「場面」です。カメラを用意したり、オブジェクトを生成したりします。
- **ゲームオブジェクト**（`IGameObject`）：プレイヤーや敵など、シーンの中で動くものです。
